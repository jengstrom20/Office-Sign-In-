Link Kiosk to Your Google Sheet

Every student check-in will automatically append a new row in real-time to your specified Google Sheet.

How to setup in 2 minutes:

  1. Open your Google Sheet and click Extensions > Apps Script.
  2. Replace any existing code with the snippet below and click Save (💾):
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.studentName,
    data.grade,
    data.staff,
    data.status || "Waiting"
  ]);
  return ContentService.createTextOutput("Success");
}
  1. Click Deploy > New Deployment.
  2. Select type: Web App.
  3. Set Execute as to: Me.
  4. Set Who has access to: Anyone.
  5. Click Deploy, copy the Web App URL, and paste it in the box above!
